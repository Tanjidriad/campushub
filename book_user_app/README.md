# book_user_app – CampusHub Pro Mobile

Flutter mobile app for the CampusHub Pro / book sale marketplace template.

This app is designed to work with the `book_backend` Node.js API and provides
authentication, listings, chat, offers, notifications, and profile management
for end users.

## Quick Start

1. Install Flutter dependencies:

```bash
cd book_user_app
flutter pub get
```

2. Make sure the backend API is running (see `Documentation/02-Installation-Backend.md`).

3. Configure the API base URL and Google Maps API key as described in:

- `Documentation/03-Installation-Mobile-App.md`
- `Documentation/04-Customization-Guide.md`

4. Run the app:

```bash
flutter run
```

For full installation and customization instructions, refer to the `Documentation/`
folder at the project root.
