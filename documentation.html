Overview

CampusHub Pro is a complete student marketplace solution that allows university students to buy and sell items. It includes:

📱 User App (Flutter)

Cross-platform mobile app with listings, real-time chat, offers, reviews, dark mode, and push notifications.

🖥️ Admin App (Flutter)

Flutter-based admin dashboard with analytics, user management, listing moderation, and report handling. Supports web.

🌐 Web Admin (React)

Modern React 19 + Tailwind CSS 4 admin panel with charts, user/listing management, and responsive design.

⚙️ Backend API (Node.js)

Express.js REST API with MongoDB, Socket.IO real-time, JWT auth, Cloudinary, Firebase push, and Redis caching.

Tech Stack

Component Technology
User App Flutter 3.x, Dart, BLoC, GetIt, GoRouter, Dio, Socket.IO
Admin App Flutter 3.x, Dart, BLoC, fl_chart, Web-compatible
Web Admin React 19, Vite, TypeScript, Tailwind CSS 4, TanStack Query, Recharts
Backend Node.js 18+, Express.js, MongoDB, Mongoose, Socket.IO, JWT
Storage Cloudinary (images), MongoDB (data), Redis (cache, optional)
Notifications Firebase Cloud Messaging
Email Nodemailer (SMTP — Gmail, SendGrid, etc.)

Requirements

Backend Server

  • Node.js v18 or higher
  • MongoDB v6+ (local or MongoDB Atlas free tier)
  • Cloudinary account (free tier works) — cloudinary.com
  • SMTP email service (Gmail App Password, SendGrid, Mailgun, etc.)
  • Redis (optional, for caching) — redis.io

Flutter Apps

  • Flutter SDK 3.x+
  • Dart SDK 3.x+
  • Android Studio or VS Code with Flutter extension
  • Xcode (for iOS builds, macOS only)
  • Firebase project (for push notifications)

Web Admin Panel

  • Node.js v18+ (for building)
  • Any modern web browser

App Architecture

The app follows Clean Architecture with three layers:

lib/
├── config/          # App-wide config (theme, routes, DI)
├── core/            # Shared constants, errors, theme, utils
└── features/        # Feature modules
    ├── auth/        # Authentication
    ├── listing/     # Marketplace listings
    ├── chat/        # Real-time messaging
    ├── offer/       # Buy/sell offers
    ├── review/      # User reviews
    ├── profile/     # User profile
    ├── notification/ # Push notifications
    └── onboarding/  # First-time user flow

Each feature contains: data/ (repositories, models, sources) → domain/ (entities, use cases) → presentation/ (BLoC, pages, widgets).

Dark Mode

The app includes a built-in dark mode controlled by ThemeCubit. It supports three modes:

  • System — follows device setting (default)
  • Light — always light
  • Dark — always dark

Call context.read<ThemeCubit>().toggleTheme() from any widget to cycle through modes. The preference is persisted to secure storage.

Firebase Setup (Push Notifications)

1
Create a Firebase Project

Go to Firebase Console and create a new project.

2
Add Android App
  • Register your Android app with package name
  • Download google-services.json
  • Place it in book_user_app/android/app/google-services.json
3
Add iOS App
  • Register your iOS app with bundle ID
  • Download GoogleService-Info.plist
  • Place it in book_user_app/ios/Runner/GoogleService-Info.plist
4
Backend Service Account
  • Go to Firebase Console → Project Settings → Service Accounts
  • Click "Generate new private key"
  • Save as book_backend/config/firebase-service-account.json
  • Or set the FIREBASE_SERVICE_ACCOUNT env var with the JSON content
Security: Never commit firebase-service-account.json to version control. Add it to .gitignore.

Deployment

Backend Deployment with Docker

A docker-compose.yml is included for easy deployment:

# Build and start all services
docker-compose up -d

# View logs
docker-compose logs -f api

# Stop services
docker-compose down

This starts the Node.js API, MongoDB, and Redis together. Edit the environment variables in docker-compose.yml before deploying.

Manual Deployment

  1. Set up a server (Ubuntu, Debian, etc.) with Node.js 18+
  2. Clone the repository and install dependencies
  3. Configure .env with production values
  4. Set NODE_ENV=production
  5. Use a process manager like PM2: 
    npm install -g pm2
pm2 start server.js --name campushub-api
pm2 save
pm2 startup
  6. Set up Nginx as a reverse proxy
  7. Enable HTTPS with Let's Encrypt / Certbot

Flutter App Release

# Android APK
flutter build apk --release

# Android App Bundle (for Play Store)
flutter build appbundle --release

# iOS (requires macOS + Xcode)
flutter build ios --release
Important: Before releasing, update useProduction = true in api_constants.dart and set the production URL.

FAQ & Troubleshooting

The app can't connect to the backend

  • Ensure the backend is running and accessible
  • For Android emulator: use 10.0.2.2 as the local IP (maps to host machine's localhost)
  • For physical device: use your PC's local network IP (e.g., 192.168.1.x)
  • Check that the port in api_constants.dart matches the backend's PORT

MongoDB connection fails

  • Ensure MongoDB is running: mongosh to test
  • For Atlas: whitelist your IP in Network Access
  • Check the connection string format in .env

Cloudinary uploads fail

  • Verify your Cloudinary credentials in .env
  • Check that the file is a valid image (JPEG, PNG, or WebP)
  • Ensure the file size is within limits (5MB for listings, 2MB for avatars)

Push notifications not working

  • Ensure Firebase is configured correctly (see Firebase Setup)
  • Check that firebase-service-account.json is in the backend config folder
  • On iOS: enable push notification capability in Xcode
  • On Android: ensure google-services.json is in android/app/

Email verification not sending

  • Check SMTP credentials in .env
  • For Gmail: use an App Password, not your account password
  • Check spam folder

Rate limiting in development

Rate limiting is relaxed in development mode (NODE_ENV=development). If you're being rate limited, ensure you're not accidentally running in production mode.

How to create an admin user?

  1. Register a normal user through the app
  2. Open MongoDB (Compass, Atlas, or mongosh)
  3. Update the user's role: db.users.updateOne({email: "admin@example.com"}, {$set: {role: "admin"}})
